# iChem Productivity Dashboard V2

## الوظائف
- Login بـ Supabase Auth.
- Dashboard للدورة 26 → 25.
- البيانات المحسوبة: بحث + فلترة + مراجعة + تعديل + حذف.
- تسجيل إنتاجية جديدة مع:
  - أكثر من مهندس.
  - أكثر من فني / مساعد / عامل.
  - مشروع موجود أو مشروع جديد.
  - القطاع والسعر من قاعدة البيانات.
  - Preview للحسابات قبل الحفظ.
- صفحات المهندسين / الفنيين / المساعدين / العمال.
- تفاصيل عمليات كل شخص.
- إضافة / تعديل / تعطيل أسماء الأشخاص.
- الحضور والغياب + نوع الغياب + الملاحظات.
- إدارة المشاريع: إضافة / تعديل / تفعيل / تعطيل.
- إدارة القطاعات والأسعار: إضافة / تعديل / تفعيل / تعطيل.
- صلاحيات Admin / Data Entry / Viewer.

## التشغيل
استبدل ملف index.html القديم بهذا الملف، وافتح نفس الفولدر في VS Code ثم Go Live.

## ملاحظات
- حذف العمليات حذف فعلي ومربوط بـ Audit Log.
- الأشخاص والمشاريع والقطاعات يتم "تعطيلهم" بدل حذفهم فعليًا للحفاظ على التاريخ القديم.
- تغيير سعر قطاع يؤثر على العمليات الجديدة فقط؛ العمليات التاريخية تحتفظ بسعرها وقت التسجيل.
